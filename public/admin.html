Codex 账号渠道：提供上面这些接口，Responses 支持客户端工具调用，可接入 Codex CLI，仅供自己使用。在对话里选择模型 gpt-image-2 会直接生图；普通模型在开启「对话中允许生图」后，用户要求画图时会自动调用 Codex 的生图工具。

              
OpenAI API 渠道：/v1 下所有请求原样转发到「API 上游」里的官方 Key，工具调用、Embeddings、音频等官方接口都能用，Codex CLI 也能直接接入。

调用策略

          

            

        

        

          
额度用完自动停用账号的 Codex 额度用满时自动停用、不再分配请求（「当前账号」策略下改用其他可用账号），额度重置后自动恢复。关闭时额度用满的账号只在轮询中暂时跳过，没有别的账号时仍会用它。账号卡片底部的暂停按钮可以手动停用 / 启用。

          

        

      

      

    


    
    

      

        
API 上游
添加 OpenAI 官方 API Key。「OpenAI API」渠道的下游 Key 会把 /v1 请求原样转发到这里，费用记在这些 Key 所属的 OpenAI 账户上

        

          

          
        

      

      

        

        
按优先级从高到低使用，相同优先级轮流分摊。遇到 401/403/429/5xx 或连不上时自动换下一个，出错的 Key 冷却一段时间（Key 无效 10 分钟，限流按 retry-after，其他 15–30 秒）后再优先使用。流式输出开始后不会切换。

      

    


    
    

      

        
调用日志
每次调用 /v1 接口和调试台的记录，只记元数据不记内容，保留 32 天

        

          

          
          
        

      

      
调用日志不可用当前 Node 不支持 node:sqlite，需要 Node 22.13 以上版本。

Codex 账号告警
单独发一条「Codex 账号告警」消息，写明是哪个账号 · 修改后自动保存

          

            
账号失败率过高某个账号近分钟的失败率 ≥%，且至少有次请求时告警。按每次尝试统计：失败后换了账号的那次也算在原账号上；请求体错误、内容被安全策略拒绝不算。

            

          

          

            
账号登录失效账号的登录凭据失效、需要重新登录时告警。手动停用的账号不告警。

            

          

          

            
额度快用完账号的 Codex 额度用到%时提醒，用完时再提醒一次（开启「额度用完自动停用」时会说明已自动停用）。

            

          

          

            
没有可用的 Codex 账号所有账号都停用、额度用完自动停用或登录失效时告警，Codex 账号渠道的请求这时会失败（开了「失败时改用 API 上游」则交给上游）。

            

          

        

        

          
API 上游告警
单独发一条「API 上游告警」消息，写明是哪个上游 · 修改后自动保存

          

            
上游失败率过高某个 API 上游近分钟的失败率 ≥%，且至少有次请求时告警。上游出错后自动换下一个上游的，那次失败也记在原上游上。

            

          

          

            
上游 API Key 无效上游返回 401（Key 被删除、失效或填错）时告警。停用的上游不告警。
